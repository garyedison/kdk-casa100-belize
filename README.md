# CASA 100 — Belize modular village

Working proposal from **KDK Technology Ltd** to **Mr. Ian Courtenay**, Senior Investment & E-Governance Officer, Office of the Prime Minister, Belmopan.

One hundred finished-ready container homes on ¼-acre lots: kitchen, toilet, shower, split air, rooftop solar (panels + grid-tie inverter, **no battery**). Unfurnished base; FF&E optional.

## Labour (EST. Sep 2026 — hours TBD)

- **11.01** Set container on pad — **US$12.80/hr** mixed, **80% Belizean / 20% China factory tech**
- **11.02** Solar PV + inverter install — **US$19.40/hr** mixed, **70% Belizean electrician / 30% China PV tech**
- Belizean standing crew **12 months or longer** (35–50 concurrent). Chinese technicians train the first pads and stand down. Village civil ~95% Belizean.

Solar kit (04.02–04.04) is **equipment only**. Crane 03.03 is **plant hire only**.
